# 변경 해설서 — PRD v1.1 → v1.2, TRD v0.5 → v0.6

2026 학술제 초파리 커넥톰 팀 · 2026-11-10

**한 줄 요약.** 11/05 ~ 11/10에 구현하고 실측하면서 바뀐 것을 PRD · TRD에 모은다. 이 문서는 "무엇을 바꿨나"보다 **"왜 바꿔야만 했나"**를 남긴다. 나중에 포스터 질문, 새 팀원, 다음 AI 도구가 이 문서 하나로 설계의 뜻을 알 수 있게 한다.

# 0. 읽는 법

## 0.1 항목의 모양

각 항목은 같은 다섯 칸으로 쓴다.

| 칸 | 뜻 |
|:--|:--|
| **무엇** | 전 → 후 |
| **왜** | 바꾸게 된 계기 |
| **왜 반드시** | 바꾸지 않으면 무엇이 깨지는가 |
| **의미** | 설계 의도, 포스터 · 해석에 주는 뜻 |
| **출처** | D§ = `docs/DECISIONS.md`의 절, PR# = 저장소 풀 리퀘스트 |

## 0.2 근거의 출처와 한계

- 1차 근거는 `DECISIONS.md`다. 결정할 때 그 자리에서 이유와 함께 적은 기록이다.
- 2차 근거는 저장소 커밋 · PR 기록과 claude.ai 프로젝트 대화(11/03 ~ 11/10)다.
- 대화를 한 턴씩 모두 다시 읽지는 않았다. 의중을 DECISIONS가 적지 않은 곳만 대화에서 보충했다. 그런 곳은 "(대화)"로 표시한다.
- 숫자는 DECISIONS · PR 보고에 적힌 값만 옮겼다. 새로 만든 숫자는 없다.

## 0.3 PRD를 고치는 이유

TRD v0.5까지는 "PRD는 웬만하면 고치지 않는다"였다. [권장]은 TRD에서 대체하고, [확정]의 애매한 문구는 TRD 18절에서 해석했다.

v1.2에서 PRD를 고친다. 이유는 셋이다.

1. **대체가 쌓여 PRD가 실제와 달라졌다.** 뇌 출력식, 학습 차단, B0, 난이도, $g$ 정하는 법이 모두 TRD에서 바뀌었다. 포스터 담당과 새 팀원은 PRD를 먼저 읽는다.
2. **[미결]이 여럿 풀렸다.** 회로, 뇌 파라미터, $p$ · $q$.
3. **PRD에 틀린 문장과 깨진 수식이 있었다.** 5.8(나)의 측지선 문장, 7.3의 "신용이 정확", 깨진 $\partial$.

**[확정]의 뜻은 하나도 바꾸지 않았다** (4절에서 확인).

# 2. 주제별 해설

## A. 실행 계약

### A1. 이동(`moved`)과 확정(`committed`)을 나눈다

- **무엇.** `step_flies`가 `(events, executed, active)` → `(events, moved, committed, active)`. 뇌는 `committed`로만 학습한다.
- **왜.** Codex 점검(F04)에서 찾았다. "칸을 옮겼다"와 "결정을 받아들였다"는 다르다. 복도 이동과 집 출구 통과는 움직였지만 결정이 아니다. 파워 전환의 지연 반전은 결정했지만 그 틱에 움직이지 않는다.
- **왜 반드시.** 하나로 쓰면 복도 이동마다 흔적이 쌓이거나, 지연 반전의 결정이 학습에서 빠진다. 행동을 낸 정책과 흔적에 쓴 정책이 어긋나 REINFORCE형 기울기의 전제가 깨진다.
- **의미.** "학습은 결정에만 일어난다"를 코드 계약으로 못 박았다. 11개 경우의 표와 엔진 무관 불변식 시험이 이것을 지킨다. core 계약이라 진짜 엔진도 따른다.
- **출처.** D§4.1, D§12.2, PR #6, PR #20.

### A2. 6.1의 8번 호출 순서: `on_release` → `commit` → `on_eaten`

- **무엇.** TRD v0.5는 `commit` 뒤에 `on_release`였다.
- **왜.** M0 구현 검토에서 모순을 찾았다.
- **왜 반드시.** 그 순서면 같은 틱에 `ALL_RELEASED` 뒤에 나온 **활성** 결정의 흔적이 `on_release`($e = 0$)로 지워진다. TRD 4.5("네 마리가 나온 뒤부터 학습")와 정면으로 어긋난다.
- **의미.** `commit`이 결정별 `active`로 거르므로, 순서를 바꿔도 비활성 결정은 흔적에 들어가지 않는다.
- **출처.** D§4.

### A3. 한 틱 처리는 `core/tick.py`의 `TickCore` 한 곳

- **무엇.** 실행기와 PPO 학습 환경이 같은 `TickCore`를 쓴다. 한 틱은 `begin()` → `finish(팩맨 행동)` 두 단계.
- **왜.** PPO 학습 루프는 관측 → 행동 선택 → 한 스텝 순서라 콜백 방식이 맞지 않았다.
- **왜 반드시.** 틱 순서가 두 곳에 있으면 팩맨이 학습한 세계와 실험하는 세계가 조금씩 달라진다. PRD 8절("우리 엔진에서 직접 학습")의 전제가 무너진다.
- **의미.** "규칙은 한 곳에만"(원칙 1)을 실행 순서에도 적용했다.
- **출처.** D§7, PR #10.

### A4. 틱 번호의 주인은 실행기

- **무엇.** 동결된 틱도 매 틱 번호를 올린다. 사건 틱 = 재생 프레임 번호. 엔진의 `view.tick`이 다르면 멈춘다.
- **왜.** 가짜 엔진이 동결 틱을 세지 않아 목숨마다 `ev_tick`이 1씩 밀렸다.
- **왜 반드시.** 재생 영상에서 포획 표시가 엉뚱한 프레임에 찍히고, `games.csv`의 틱 수가 모자란다.
- **출처.** D§8, PR #8.

### A5. 난수는 (시드, 판 번호, 용도)로 칸마다

- **무엇.** 판을 시작할 때마다(판 1 포함) 엔진 · 유령 · 팩맨 난수를 다시 만든다. `reset_game(mask, rngs)`.
- **왜.** 점검(F05)과 그 뒤 검토에서 엔진이 판 0 생성기 하나를 모든 판에 쓰고, 팩맨은 칸들이 생성기 하나를 나눠 쓴 것을 찾았다.
- **왜 반드시.** 묶음 크기 · 칸 순서에 따라 결과가 달라지면 **짝지은 비교**(PRD 10.6)가 성립하지 않는다. 같은 시드가 같은 게임이어야 체제 차이만 남는다.
- **의미.** 판 경계 재개(13.6)도 이 덕분에 판 번호만 있으면 된다.
- **출처.** D§3, D§11, PR #10.

### A6. 은퇴(`retire`)와 재생 기록 복사

- **무엇.** 모든 판을 끝낸 칸은 새 판 없이 학습 활성만 내린다. 재생 버퍼는 값을 복사해 쌓는다.
- **왜 반드시.** 은퇴 칸의 학습 활성이 켜진 채 남으면 종료 뒤 사건이 학습될 수 있다. 복사하지 않으면 과거 프레임이 나중 값으로 **덮어써진다** (치명 버그, 점검 F01).
- **출처.** D§3, D§7, D§11, PR #6.

## B. 뇌 모델

### B1. 기준선 빼기

- **무엇.**

$$
m_a = \frac{1}{k|a|}\sum_{j \in a}\sum_i w_{ij}\,k_i
\quad\longrightarrow\quad
m_a = \frac{1}{k|a|}\sum_{j \in a}\sum_i \big(w_{ij} - w^{(0)}_{ij}\big)\,k_i
$$

- **왜.** 미결 2(PN 채널 · MBON 묶음 배정)를 풀다가 나왔다. 배정은 프로젝트가 정한 인공 대응이다. 원래 식이면 학습 전에도 배정 때문에 특정 방향 편향이 생긴다. 처음 제안은 "편향이 작은 배정을 고른다"였고, 외부 검토 두 차례 끝에 이 식으로 바꿨다 (대화, 11/06).
- **왜 반드시.** 편향을 배정으로 줄이면, 결과가 "어떤 배정을 골랐나"에 묶인다. 우리가 고른 배정의 우연이 체제 비교에 섞인다. 빼기로 하면 학습 전 버섯체 출력이 **구조적으로 정확히 0**이다.
- **의미.** 학습 전 행동은 외측뿔 본능 $g\,o_a$만 정한다. 연결 구조는 여전히 **무엇을 배울 수 있는가**(KC 표현, 연결 마스크 $M$)에 영향을 준다. 포스터 문구: "인위적으로 부여한 방향 대응에서 나오는 초기 정책 기여를 연구 대상에서 제외한다. 연결 구조가 표현과 학습에 미치는 영향은 유지한다." 생물학적 설명은 "인공 판독 규칙".
- **출처.** D§10.1, D§10.3, D§12.3.

### B2. 학습 상태는 변화분 $dw$ 하나

- **무엇.** $w$를 따로 두지 않고 $dw = w - w^{(0)}$만 저장 · 갱신한다. 비음수 제한은 $dw \ge -w^{(0)}$.
- **왜 반드시.** $w$와 $dw$를 둘 다 두면 어긋날 수 있고, $w$에서 $w^{(0)}$을 다시 빼는 반올림 때문에 재개한 실행이 끊지 않은 실행과 달라진다. 학습 전 $m_a = 0$이 반올림 없이 정확히 성립한다.
- **출처.** D§12.3, D§12.5, PR #7.

### B3. 증거 누적은 `propose`에서

- **무엇.** TRD 5.5는 "`propose`는 상태를 바꾸지 않는다"였다. 이제 틱당 한 번 감각 증거 $x$, $h$를 누적한다. 학습 상태($w$, $e$, $\bar R$)는 바꾸지 않는다.
- **왜 반드시.** 실행기가 매 틱 부르는 것은 `propose`와 `commit`뿐이다. 결정이 증거를 읽으려면 누적이 `propose`에 있어야 한다. TRD 5.5와 10.3이 서로 모순이었다.
- **의미.** 출발 전(집 안)에도 쌓는다. 그래야 "출발 전에 맡은 냄새는 첫 활성 결정에 쓴다"(TRD 10.4)가 성립한다.
- **출처.** D§12.1.

### B4. 결정 지점 두 종류와 지연 반전

- **무엇.** ① 보통 갈림길(이번 틱에 이동하고 선택지 ≥ 2), ② 파워 전환으로 관측의 $z$가 바뀐 뒤 첫 결정. ②에서 속도가 모자라면 방향을 **저장**하고 다음 이동 때 적용한다.
- **왜.** PRD 4.3의 반전 예외를 속도 누적기(틱마다 움직이지 않음)와 맞추려면 "결정했지만 아직 못 움직인" 상태가 필요했다.
- **의미.** 반전 기회는 PRD 4.3대로 파워 시작 · 종료에만, 정확히 한 번.
- **출처.** D§4.1(7 ~ 11행), D§12.2, PR #20.

### B5. 배열은 float64

- **무엇.** TRD 10.5의 float32 추정 → float64. $w$(내부 $dw$)와 $e$가 각 22.6 MB.
- **왜.** 정밀도를 유지하고, 메모리가 충분하다 (32 GB).
- **출처.** D§12.3, D§12.6.

## C. 기준선과 조건 수

### C1. B0′ 추가(v0.3) → 흡수(v0.6). 본 실험은 5조건

- **무엇.** 체제 1 · 2 · 3, B0, B0′, B1 (6조건) → 체제 1 · 2 · 3, B0, B1 (**5조건**). 설정의 `b0p`는 오류.
- **왜 처음에 넣었나 (11/05).** PRD 9의 B0는 "본능만(버섯체 출력 0)"이다. 그런데 원래 출력식에서는 학습 전 버섯체 출력이 0이 아니다. 그래서 "학습만 끈 회로"(B0′)를 따로 둬야 학습 효과(체제 대 B0′)와 초기 출력 효과(B0′ 대 B0)를 나눠 볼 수 있었다. PRD를 바꾸지 않으려는 결정이었다.
- **왜 뺐나 (11/06).** 기준선 빼기(B1)로 학습 전 출력이 0이 되었다. 그러면 B0′와 B0가 **같은 정책**이다.
- **왜 반드시.** 같은 정책을 두 조건으로 돌리면 계산만 늘고, 둘의 차이는 순수한 잡음이라 해석을 흐린다.
- **의미.** B0 = 같은 코드, $w = w^{(0)}$에서 시작, $\eta = 0$. PRD 9의 "본능만"이 해석 없이 글자 그대로 성립한다. 회귀 시험(학습 전 뇌 $\pi$ = B0의 $\pi$)으로 지킨다.
- **출처.** D§10.4, D§12.4.

### C2. 기준선은 보상을 받지 않는다 (`NullRegime`)

- **무엇.** B0 · B1은 보상 0, 페로몬 0. 알 수 없는 조건 이름은 오류(전에는 조용히 체제 1).
- **왜 반드시.** 조건 이름 오타가 체제 1 실험으로 둔갑하면 결과를 보고도 모른다.
- **출처.** D§7.

## D. 회로

### D1. 추출 문턱과 제외 목록 (미결 5 해결)

- **무엇.** $s_{\min} = 3$을 **맨 먼저**, $\theta_{\text{PN}} = 50$, $\theta_{\text{KC}} = 0.8$, KC 최소 입력 20, $\theta_{\text{MBON}} = 100$. 결과: PN 106 (사구체 51), KC 1,575, MBON 47.
- **왜.** 목록 조사 결과를 보고 **학습 결과를 보기 전에** 데이터 품질만으로 정했다.
- **의미.** 재구성 오류 가능성이 있는 약한 연결과 조각난 뉴런을 거른다. lvPN은 흥분성으로 **가정**했다 (서버 확인 불가).
- **출처.** D§10.6, D§10.8, PR #5.

### D2. PN 9채널 · MBON 4묶음 배정 (미결 2 해결)

- **무엇.** MBON 묶음은 KC 종류별 연결 균형을 최소화하는 결정론적 배정 (시드 무관). PN은 사구체 단위로 채널에 무작위 분할, 배정 시드 0 ~ 19를 결과 전에 고정.
- **의미.** 배정은 **프로젝트가 부여한 대응**이고 생물학적 근거를 주장하지 않는다. 편향은 배정이 아니라 기준선 빼기(B1)가 없앤다.

## E. 회로 선정과 학습 장치 검증

### E1. 표현력 시험: 통과 0개 → 판정에서 진단으로

- **무엇.** 배정 시드 20개 × $(\rho, \theta)$ 격자 9개 = 180개 조합을, 사전 고정한 규칙으로 시험했다. **통과 0개.** 규칙을 바꾸지 않고 "후보 없음"으로 닫았다. 표현력 시험은 관문에서 진단으로 내렸다.
- **왜 내렸나.** 처음부터 표현력 시험은 대리 시험이었고, 최종 판정은 작은 과제 C라고 정해 두었다. 통과선 0.90은 근거 없는 개발용 값이었다. 대리 시험은 실제 과제보다 엄격했다 (선택지 셋, 약한 구배, 0.90).
- **왜 결과를 보고 기준을 바꾼 것이 아닌가.** 외부 검토(Sol)가 이 질문을 직접 따졌고 "수정 후 채택"이었다. 기존 시험은 기록 그대로 보존하고, 새 절차는 별도로 정했다. 새 절차에서도 결과 전에 순서를 고정했다 ($\rho$ 0.05 먼저, 실패 시 0.10. 대비책 B의 발동 조건 사전 고정).
- **의미.** 결론의 범위를 줄였다: "현 배정 · 판독기 · 시험한 $z$ 입력 크기에서 이득 조절만으로 큰 개선을 관찰하지 못했다." **구조적 한계로 단정하지 않는다.**
- **출처.** D§13, D§17, 대화 (11/09).

### E2. 회로는 배정 시드 0, $\rho = 0.05$, $\theta = 0$

- **왜.** 시드 20개가 거의 같게 행동해 고를 의미가 없었다. 사전 순서의 첫 시드를 쓴다. $\theta = 0$은 모든 시험에서 문턱이 해로웠다. $\rho = 0.05$는 실제 KC 희소도(약 5%)에 가까운 쪽을 먼저 시험해 "결과가 좋은 값을 골랐다"는 의심을 피한다.
- **의미.** 보고 범위는 **시드 0 회로**이며 다른 시드로 일반화하지 않는다. 같은 회로를 모든 조건에 쓴다.
- **출처.** D§17.3.

### E3. 뇌 하이퍼파라미터는 사전 고정 규칙으로 (미결 3 · 4의 뇌 부분)

- **무엇.** PRD 6.7은 "$g$는 학습 전 포획률로 맞춘다"였다. 이제 $\kappa, g, \beta, \eta, \alpha, \gamma$를 **목표 범위와 고르는 규칙을 먼저 고정한 뒤** 잰다. 작은 과제 정답률은 보지 않는다.
- **고른 값.** $\kappa = 0.2$, $g = 0.03747$, $\beta = 4$, $\eta = 1.129$, $\alpha = 0.01$, $\gamma = 0.9$.
- **왜 반드시.** 포획률이나 정답률로 맞추면 과제를 보고 값을 조정하는 셈이라, 나중의 "학습했다"가 순환 논증이 된다.
- **핵심 식.** 학습 전 두 선택지의 로짓 차이

$$
\Lambda_0 = \beta\,g\,m\,S, \qquad S = \frac{1-(1-\kappa)^{L+1}}{\kappa}
$$

를 목표 범위 $[0.28, 0.75]$의 기하평균 0.458로 둔다 (본능만의 냄새 쪽 확률 약 0.61). $\eta$는 한 번 학습의 로짓 이동 $s$와 앞 20시행의 가중치 변화량 두 조건으로 정한다.

- **의미.** 결정 엔트로피 $H/\ln 2$가 학습 전 0.963으로, 처음엔 충분히 탐험한다.
- **한계.** 복도 길이 $L = 10$으로 정한 값이다. 게임의 실제 결정 간격 분포는 M3에서 확인한다.
- **출처.** D§17.7, D§18.

### E4. 작은 과제 A ~ D 통과 (M2 완료 조건)

| 과제 | 기준 | 결과 | $\eta = 0$ 대조 |
|:--|:--|:--|:--|
| A 방향 (좌 · 우 보상) | ≥ 0.80 | 5/5, 5/5 | 전부 탈락 |
| B 냄새 | ≥ 0.80 | 5/5 ($g = 0$ 평가 0.98 ~ 1.00) | 전부 탈락 |
| C 상태 전환 | 네 조합 ≥ 0.75 | 5/5, 확인 시드 5/5 | 전부 탈락 |
| D 지연 $n = 0, 5$ | ≥ 0.70 | 5/5, 5/5 | 전부 탈락 |

- **의미.** 이 커넥톰 회로는 이 학습 규칙으로 **같은 냄새에서 상태에 따라 행동을 뒤집는 법을 배운다.** 학습 없이는 풀리지 않는다. 본능을 꺼도 푼다.

## F. 보상 체제

### F1. $q = 1$, $p = \frac13$ (미결 4 해결)

- **$q$.** 먹힘의 팀 합은 모든 체제에서 $-q$로 같다. 그래서 $q$는 체제 비교를 기울이지 않는다. 크기는 포획 $+1$과 대칭이고, 작은 과제에서 $\pm 1$로 학습이 확인됐다.
- **$p$.** 체제 1 포획의 팀 합 $1 - 3p$. $p = \frac13$이면 0, 곧 **제로섬**이다. 체제 1이 "남의 성공은 곧 내 손해"라는 성격을 가장 깨끗하게 가진다. $p$는 자기 행동과 무관한 잡음 항의 계수라 $\frac12$은 피했다.
- **왜 결과 전에.** 체제 결과를 본 뒤 정하면 원하는 체제가 이기도록 고를 수 있다.
- **출처.** D§20, PR #34.

### F2. 체제 1 · 2를 한 식으로 읽기

$$
R_i = a\,c_i + b\,(C - c_i),
\qquad
(a, b) =
\begin{cases}
(1, -\tfrac13) & \text{체제 1}\\
(\tfrac14, \tfrac14) & \text{체제 2 · 3}
\end{cases}
$$

- **의미.** 체제 1 대 2는 **두 가지를 동시에** 바꾼다. 남의 포획에 대한 부호($b$)와 자기 신호의 크기($a$, 4배). 체제 2가 지면 협동이 나빠서인지 느리게 배워서인지 이 비교만으로는 가를 수 없다.
- **대응.** 조건은 늘리지 않고, M3 · M5에 "받은 보상 총량 기준 학습곡선"을 진단으로 더한다. 판정 지표는 바꾸지 않는다.
- **참고 (대화).** MARL의 관행: 추격 벤치마크는 기여자 보상이나 팀 공유 보상을 쓰고, 공유 보상의 고질병은 "게으른 에이전트"다. 남의 성공에 직접 고통을 주는 항($-p$)은 흔하지 않고, 그것이 체제 1의 특색이다.
- **출처.** D§20, TRD 11.

### F3. TRD 5.6 예시의 덮어쓰기 정정

- **무엇.** `R[ev.fly] = 1.0` → 사건마다 더한다.
- **왜 반드시.** 한 틱에 사건이 둘이면 앞 사건의 값이 지워진다. 그리고 기록기는 사건마다 따로, 뇌는 한 번에 계산하므로 **선형성**이 깨지면 기록된 R과 뇌가 받은 R이 어긋난다.

$$
\texttt{rewards}(e_1, e_2, \dots) = \sum_k \texttt{rewards}(e_k)
$$

- **출처.** D§20, PR #35.

### F4. 기본값의 출처는 하나

- **무엇.** $p$, $q$ 기본값을 공통 생성자에서 체제 1 · 2 · 3 모두에 적용. 기록기는 체제 객체의 최종값을 저장.
- **왜 반드시.** 체제 3만 다른 출처를 쓰면 $q_3 \ne q_1$이 될 수 있다. PRD 7.2(공정 비교: 변하는 것은 보상 함수와 페로몬뿐)를 어긴다.
- **시험.** $q_1 = q_2 = q_3$, 체제 2와 3의 보상 동일 ($R^{(2)} = R^{(3)}$), 변이 검사로 시험이 옛 버그를 잡는 것까지 확인.
- **출처.** PR #35, PR #36.

\sum_k R_k =

### G1. 학습 보상의 시점

# 5. 바뀐 것 아래의 원칙

이번 변경들을 꿰는 원칙은 다섯 개다. 다음 결정도 이 원칙으로 판단한다.

1. **결과 전에 고정한다.** 문턱, 배정 시드, 하이퍼파라미터 규칙, $p$ · $q$, 페로몬 전환 조건, 대비책 발동 조건을 모두 결과 전에 적었다. 결과 뒤에 바꾸면 사유를 기록한다.
2. **대리 시험과 판정을 구분한다.** 표현력 시험은 대리였고, 판정은 작은 과제였다. 작은 과제 통과도 "학습 장치가 작동한다"이지 "게임에서 배운다"가 아니다.
3. **해석의 범위를 줄여 말한다.** "구조적 한계"가 아니라 "이 조건에서 관찰하지 못함". "체제 2가 협동에 졌다"가 아니라 "부호와 크기를 함께 바꾼 묶음이 졌다".
4. **출처는 하나.** 틱 처리, 난수, 기본값, 회로, 틱 번호가 모두 한 곳에서 나온다. 둘이면 언젠가 어긋난다.
5. **시험이 버그를 잡는지 본다.** 고친 코드에서 통과하는 것만으로는 부족하다. 옛 버그를 되살려 시험이 실패하는지 본다 (변이 검사). CI가 건너뛰는 시험은 시험이 아니다.
